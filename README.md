# AI Smart Study Companion

## Overview
AI-powered study assistant that helps students learn faster from PDF documents.

## Features
- PDF Upload
- Text Extraction
- AI Summary
- Flashcards
- MCQs
- Important Questions
- Revision Plan
- Chat With PDF

## Technologies Used
- Python
- Streamlit
- Gemini AI
- PyPDF2

## How To Run

pip install -r requirements.txt

python -m streamlit run app.py
